MD ASIF — PERSONAL PORTFOLIO
Files:
- index.html: page content and sections
- style.css: responsive visual design
- script.js: mobile menu, scroll progress, current year

BEFORE PUBLISHING:
1. Open index.html and replace YOUR_EMAIL@example.com with your real email.
2. Replace the GitHub and LinkedIn profile URLs with your actual profiles.
3. Review the project descriptions and keep only details that accurately represent your work.
4. Add a real profile photo if you want one (optional).

DEPLOY WITH GITHUB PAGES:
1. Create a GitHub repository named asif-portfolio (or any available name).
2. Upload index.html, style.css, and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. Your link will look like:
   https://YOUR-GITHUB-USERNAME.github.io/asif-portfolio/
7. Open the live link on desktop and mobile to test it.
8. Submit the actual working URL in the assignment Google Sheet.
